## 👻 About the Project
A hyper-immersive, cinematic paranormal defense portal and digital folklore archive inspired by the legend of **Stree** and the **Chanderi Paranormal Universe**, crafted exclusively for **SPOOK-A-THON 2026**.

Developed by **Rudraksh Garg** (1st Year, B.Sc Hons.) representing **TEAM BLACKHAT**, in strategic tech alliance with **KAPIDHWAJ INNOVATIONS**.

## ⚡ Key Features
- 🩸 **Digital Alta Inscriber**: Inscribe *"O Stree, Kal Aana"* with digital bat-blood ink to ward off apparitions.
- 🪔 **Trikal Deepam (3-Diya Ritual)**: Interactive warded lighting sequence that unseals the town defense perimeter.
- 🔍 **Dangerous Evidence Zoom Modal**: Click any evidence case file to inspect high-resolution forensic paranormal anomalies with ominous voice synthesis.
- 💀 **Corner Dancing Skeletons & Centered Music Hub**: Synchronized dancing skeletons flanking the official high-fidelity soundtrack (`NIVIRO - The Ghost`).
- 🎬 **Uncropped Threat Transmission**: Full-aspect-ratio vertical video archive (`stree_video.mp4`) muted for pure atmospheric immersion.
- 📜 **Chanderi Police Special Branch FIR Registry**: Live search through classified missing persons cases and headless Sarkata terror files.
- 🔊 **Cinematic Hindi Dialogue Soundboard**: Iconic voicelines from Vicky, Rudra, and Bittu.
- 🤝 **Kapidhwaj Innovations Command Suite**: Official sponsor emblem with direct Instagram transmission links (`@kapidhwaj.innovations`).
